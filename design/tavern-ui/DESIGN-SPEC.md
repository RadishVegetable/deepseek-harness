# 酒馆 Tavern · UI 设计规范与验收标准

> 版本 v1.0 · 2026-08-30 · 交付给前端设计师，用于开发与验收
> 配套高保真原型：`index.html`（含全部页面、状态与交互演示）

---

## 0. 一句话设计主张

**「酒馆 Tavern 是一个沉浸的故事空间，不是开发者工作台。」**
第一屏用户看到的永远是：**角色立绘 + 名字 + 当前场景 + 最新一段剧情**。技术控件全部收进二级入口。

---

## 1. 设计 Token（Design Tokens）

### 1.1 颜色 Color

基调：**昏暗木质 + 暗色中性底**，点缀**铜 / 红 / 青**。避免单色仪表盘感，避免大面积渐变。

| Token | 值 | 用途 |
|---|---|---|
| `--bg-void` | `#120e0a` | 页面最底层背景 |
| `--bg-base` | `#1a1510` | 主背景（暖色倾向，非纯黑） |
| `--bg-surface` | `#221b14` | 面板 / 卡片底 |
| `--bg-elevated` | `#2a2118` | 浮层 / hover 抬高 |
| `--bg-hover` | `#33281c` | 悬停态 |
| `--wood` | `#4a3826` | 木质装饰（品牌 Logo、分隔） |
| `--copper` | `#c99b64` | **主强调色**（按钮、选中、光标） |
| `--copper-soft` | `#e3c391` | 铜色亮态（hover / 高亮） |
| `--copper-dim` | `#8a6d47` | 铜色弱态（分割、装饰线） |
| `--red` | `#c95a43` | **语义红**：冲突警示、危险操作 |
| `--red-soft` | `#7c3b2d` | 红色弱态 |
| `--teal` | `#57a89c` | **次级点缀青**：世界书、诊断、可选态 |
| `--teal-soft` | `#2f5d57` | 青色弱态 |
| `--text-1` | `#ece2d1` | 主文字（暖白） |
| `--text-2` | `#c3b49c` | 次文字 |
| `--text-3` | `#8d7e69` | 弱文字 / 说明 |
| `--text-4` | `#5d5346` | 禁用 / 占位符 |
| `--line` | `#2e261d` | 常规边框 |
| `--line-strong` | `#403428` | 强调边框 |

**对比度验收（WCAG AA）**：主文字 `#ece2d1` 于 `#1a1510` 背景对比度 ≈ 12.5:1 ✅；次文字 `#c3b49c` ≈ 7:1 ✅；弱文字 `#8d7e69` ≈ 4.6:1 ✅（仅用于辅助说明，正文禁用）。

> 情绪色规约：**红 = 冲突/危险**，**青 = 世界书/次要/中立**，**铜 = 品牌主色/行动**。全站严格三色点缀，不引入第四种情绪色。

### 1.2 字体 Typography

| Token | 值 | 用途 |
|---|---|---|
| `--font-story` | `"Source Han Serif SC","Noto Serif SC","Songti SC","STSong",serif` | **剧情正文**（衬线，文学感） |
| `--font-ui` | `"PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui` | 界面控件 |
| `--font-mono` | `ui-monospace,Consolas` | 仅诊断视图技术字段 |

**中文排版专项规范（长段落舒适度）：**
- 剧情正文：`font-size 17px`，`line-height 2.0`，`text-align justify`，`letter-spacing 0.3px`。
- 段落间留白 `16px`；剧情「段落块」之间留白 `34px`，以留白体现**时间 / 地点 / 人物切换**。
- 阅读列宽 ≤ `640px`（约 35 个汉字），居中，保证行长舒适。
- 对话与叙述区分：**叙述** = 正文色；**对话** = 左侧 2px 铜色竖线 + 铜色字，形成视觉停顿。

### 1.3 间距 Spacing（4px 基准）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`（`--s1` ~ `--s12`）。
组件内部用 4–16px；区块间用 24–48px 制造节奏。

### 1.4 圆角 Radius

`6px`（控件）· `10px`（按钮/输入）· `14px`（卡片）· `20px`（大面板）。
**页面主体不封框**——只有「重复项」（角色卡列表、右侧栏目块、审计条目）用卡片圆角。

### 1.5 阴影 & 动效

- 三级阴影：`--shadow-1`（近）`--shadow-2`（中）`--shadow-3`（远，用于立绘/抽屉）。
- 动效 `--t-fast 150ms / --t-med 280ms / --t-slow 450ms`，缓动 `cubic-bezier(.2,.7,.3,1)`。
- 全站覆盖一层 `3.5%` 噪点纹理（`mix-blend-mode: overlay`），消除扁平仪表盘塑料感。

## 2. 页面结构

### 2.1 入口页（Entry）

- 顶部：品牌「酒馆 Tavern」+ 灯笼意象。
- 三步流：**① 选角色卡（必选）→ ② 选世界书（可选）→ ③ 玩家身份（昵称/人设）→ 开始旅程**。
- 角色卡 = 卡片（立绘 + 名字 + 一句话简介），选中态用**铜色描边 + 右上角 ✓**。
- 空态：无角色卡时展示「导入」卡片（**JSON / PNG 拖拽**）。
- 世界书卡片用**青色**标识（区分「角色=铜 / 世界=青」的语义），含「暂不选择」空态。

### 2.2 旅程页（主界面 · 重点）

**左：故事舞台（视觉中心）**
- 顶部场景 banner：场景图 + 渐隐遮罩 + 时间/地点/天气 chips + 场景标题/摘要。
- 立绘卡片**悬浮**在 banner 右下，压出层次（真实图片，非占位）。
- 剧情流：衬线正文，分段留白体现切换，滚动区。
- 底部输入框：自适应高度；发送按钮为铜色圆角方钮；`focus` 态铜色描边。

**右：旅志面板（核心新设计）**
- 面板头：标题「旅志」+ **审计入口 🕮 + 设置 ⚙ + 折叠 ◀**。
- Tab 切换：**角色 / 世界观**，两个栏目组**并行可看**（不再「看角色必须先关世界书」）。
- **栏目化（结构化）：** 每个栏目是一张卡片，内含若干「键—值」事实行。栏目**不固定、可增减、可改名、可排序**。
- **冲突警示：** 当 AI 新设定与已记录矛盾，该栏目整卡**红色描边 + 脉冲动画**，卡内出现裁决条，提供「**保留新值 / 抛弃**」一键裁决，操作后即时反馈。
- 操作在 **hover 浮现**（编辑 ✎ / 删除 🗑 / 拖动手柄 ⋮⋮），不设层层菜单。

### 2.3 历史页

- 旅程列表（卡片 = 重复项）：缩略图 + 标题 + 元信息（角色/世界/时间/段数）+ 箭头。点击恢复。

### 2.4 诊断视图（与主流程视觉隔离）

- 顶部横幅带「独立于主流程」标识，采用**偏冷蓝黑底**与主界面暖木色明确区隔。
- 内容：**Prompt 检查器**（代码块、默认收起）、**上下文激活决策**（每条含「已激活/未激活」标签 + 原因）、**模型与生成参数**、**原始数据**（asset id 等技术字段只出现在这里）。

## 3. 关键交互规范

### 3.1 动态栏目（增 / 删 / 改名 / 排序）
- 增：面板底部「＋ 添加栏目」虚线按钮 → 弹名称 → 立即插入空栏目。
- 改名：栏目头 hover 出现 ✎ → 弹框改名。
- 排序：拖动栏目头「⋮⋮」手柄，实时重排（拖拽态 `cursor: grabbing`）。
- 删：hover 出现 🗑 → 二次确认 → **可撤销**（Toast 提示）。

### 3.2 事实编辑（行内 + 保存/取消 + 撤销）
- 点击事实值 → 变 `contenteditable`，铜色虚线框。
- `Enter` 保存、`Esc` 取消（回滚原值）。失焦自动保存。
- 删除后 Toast「已删除（可撤销）」。

### 3.3 冲突裁决（一键 + 即时反馈）
- 触发：GM 新设定与已记录值矛盾 → 栏目卡红色脉冲 + 裁决条。
- 「保留新值」：写入新值，旧值进审计；「抛弃」：维持原值，变更记入审计。
- 裁决后卡片立即消除冲突态，Toast 反馈「已保留/已抛弃」。

### 3.4 流式生成态
- 输入发送后：出现「角色头像 + 三点跳动 + GM 正在续写」指示器。
- 正文逐字打出，句尾跟随**铜色竖线光标**（`blink` 动画），完成即消失。
- 生成期间发送按钮 `disabled`。

### 3.5 错误反馈（说人话）
- 禁止只弹「操作失败」。必须说明**发生了什么 + 如何恢复**。
- 例：`导入失败：JSON 缺少 "name" 字段 → 请检查文件或改用 PNG`。

## 4. 状态规范

| 状态 | 表现 |
|---|---|
| 流式生成态 | 三点指示 + 逐字 + 光标 |
| 空态 | 与主视觉同语言的插画/文案，**不退回通用后台风格** |
| 加载态 | 骨架屏（`shimmer` 动画），保持卡片比例 |
| 错误态 | 说人话 + 明确恢复路径 |
| 窄屏折叠态 | 右面板折叠为底部抽屉 + 悬浮按钮 |

---

## 5. 响应式

- **≥ 861px**：右侧面板固定 `384px`，可点击面板头「◀」折叠（`margin-right` 滑出）。
- **≤ 860px**：右侧面板转为**全屏底部抽屉**，右下角悬浮「🗂」按钮唤起。
- 场景 banner 高度 200px → 160px；立绘 108×150 → 84×118；阅读列宽自适应。
- 触控目标 ≥ 44px（移动端按钮放大）。

---

## 6. 前端开发落地建议

- 直接用 `index.html` 内 `:root` 中的 CSS 变量作为 token 源，抽成 `design-tokens.css` 全局引用。
- 组件目录建议：`CharacterCard` / `WorldCard` / `SectionCard`（栏目） / `FactRow` / `ConflictBanner` / `Beat`（剧情段） / `Composer` / `Drawer` / `AuditItem` / `Diagnostic`。
- 数据模型：栏目 `{ id, name, items: [{key, value, version}] }`，冲突由 `version` 冲突检测触发。

## 7. 验收清单（Checklist）

**视觉**
- [ ] 第一屏即为「立绘 + 名字 + 场景 + 最新剧情」，无 JSON / Prompt / asset id 泄露。
- [ ] 主背景为暖色暗底，非纯黑、非单色仪表盘；全站噪点纹理生效。
- [ ] 仅三色点缀（铜/红/青），语义一致（红=冲突、青=世界书、铜=行动）。
- [ ] 剧情正文为衬线、`line-height 2.0`、行宽 ≤640px、段落留白体现场景切换。
- [ ] 立绘/场景为真实图片；空态/加载态与主视觉同语言。

**交互**
- [ ] 角色信息与世界观可**同时查看**，无需互斥关闭。
- [ ] 栏目可增 / 删 / 改名 / 排序，操作在 hover 浮现。
- [ ] 事实可**行内编辑**，Enter 保存 / Esc 取消，误删可撤销。
- [ ] 冲突触发红色脉冲 + 「保留新值 / 抛弃」一键裁决，操作后即时反馈。
- [ ] 流式生成有逐字 + 光标效果；生成期间禁止重复发送。
- [ ] 错误提示为「发生了什么 + 如何恢复」的可读文案。

**响应式**
- [ ] ≤860px 右侧面板折叠为底部抽屉，触控目标 ≥44px。

**技术**
- [ ] 模型参数 / Prompt / 原始数据**仅存在于诊断视图与设置抽屉**。
- [ ] 事实审计抽屉按时间列出全部变更（含拒绝原因）。
- [ ] 颜色对比度满足 WCAG AA（正文 ≥4.5:1）。
