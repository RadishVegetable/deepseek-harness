# 酒馆 Tavern · 前端 UI 设计交付总览

## 一句话结论
把「酒馆」从"开发者工作台"重塑为**沉浸式故事空间**：第一屏只呈现「角色立绘 + 名字 + 当前场景 + 最新剧情」，所有技术控件收进二级入口。

## 交付物
| 文件 | 说明 |
|---|---|
| `index.html` | **高保真交互原型**（含全部页面、状态与可点交互，浏览器直接打开） |
| `DESIGN-SPEC.md` | 设计 token、页面结构、交互规范、响应式策略、**验收清单** |
| `assets/` | 3 张 AI 生成的立绘/场景图（猫娘秘书、修仙师姐、酒馆内景） |

## 覆盖范围
- **入口页**：角色卡/世界书/玩家身份三步流 + 导入空态。
- **旅程页（重点）**：左故事舞台 + 右「旅志」面板；角色/世界观栏目化并行可见；冲突裁决；事实审计抽屉。
- **历史页**：续档列表。
- **诊断视图**：Prompt 检查器 / 上下文激活决策 / 模型参数，与主流程视觉隔离。
- **状态**：流式生成、空态、加载态、错误态、窄屏折叠态。

## 关键设计决策
1. **三色语义点缀**（铜=行动 / 红=冲突 / 青=世界书），暖色暗底 + 噪点纹理，消除仪表盘塑料感。
2. **栏目完全动态**：增删改名排序 hover 浮现，事实行内编辑 + Enter 存 / Esc 取消 + 可撤销。
3. **冲突一键裁决**：红色脉冲 + 「保留新值 / 抛弃」，即时反馈。
4. **技术信息隔离**：模型参数进设置抽屉，Prompt/asset id 只存在于诊断视图。
